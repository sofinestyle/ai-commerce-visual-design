## Product

The workflow begins with product context. Product data explains what is being sold, what platform it targets, what visual constraints matter, and what brand or category expectations should guide the work.

Future product data may include SKU, product name, category, selling points, dimensions, materials, platform requirements, and brand notes.

## Media

Media provides the visual source material. This includes product photos, PSD files, transparent cutouts, reference images, brand assets, generated drafts, and export-ready images.

Media should be organized so users can understand which assets belong to which product or project.

## Project

A project turns product and media context into a specific visual production goal. Projects may represent campaigns, product launches, platform listings, seasonal promotions, or design batches.

Projects should connect products, selected media, prompt sets, generation outputs, review state, and export results.

## Prompt

The prompt expresses creative intent. It should combine product context, media references, platform requirements, style direction, and constraints.

The future AI Panel may help draft prompts, but users must review and confirm prompt direction.

## AI Generate

AI Generate produces draft visual outputs from the approved prompt, selected model, and source media.

This step should remain explicit. Users choose when generation starts and should be able to understand the inputs used.

## Compare

Generated outputs should be compared against each other and against the project goal. Users need to evaluate visual quality, product accuracy, brand fit, platform readiness, and commercial usefulness.

Comparison keeps generation from becoming a black box.

## Edit

Selected outputs may need manual or AI-assisted edits. Editing may include visual corrections, layout changes, background changes, format adjustments, or prompt refinement.

Edits should preserve user control and should eventually be recorded as part of the asset history.

## Export

Approved visuals are exported for external use. Future export workflows may support platform presets, file naming rules, sizes, quality settings, and batch export.

Export is a deliberate finalization step, not an automatic AI action.

## History

History records what happened. It should preserve generation attempts, prompts, selected models, source assets, edits, review decisions, and exports.

History makes the workflow traceable and helps users reuse successful patterns.
